# iMBrace Developer

Skills that teach the model how to build on [iMBrace](https://engineer.imbrace.co), the customer-engagement
platform for CRM data boards, conversations, AI agents, workflows and knowledge hubs.

| Skill | Use it for |
|---|---|
| `imbrace-get-started` | First use: pick an environment, get an API key safely, make one verified call |
| `imbrace-sdk` | TypeScript `@imbrace/sdk` and Python `imbrace`: client setup, namespaces, errors |
| `imbrace-mcp` | Connect the iMBrace hosted MCP server in Codex, Cursor and other clients; OAuth or API key, least access |
| `imbrace-cli` | Install, sign in and script the `imbrace` CLI |
| `imbrace-build-agents-workflows` | AI agent + streaming chat, workflows, knowledge hubs, CRM boards end to end |
| `imbrace-vibe-code` | Build, deploy and host a full app on iMBrace (follows https://engineer.imbrace.co/skill.md) |

Try: *"Help me get started with iMBrace"*.

This package contains instructions only. It does not call any service and holds no credentials. The code and
commands the skills produce use your own iMBrace API key, under the
[iMBrace privacy policy](https://www.imbrace.co/privacy-policy/) and
[terms](https://www.imbrace.co/terms-and-conditions/).

Support: https://github.com/imbrace-co/imbrace-agent-toolkit/issues
